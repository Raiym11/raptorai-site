# 3D-сцены первого экрана страниц услуг

- `hero3d.src.mjs` - исходник (Three.js + вёрстка в 3D-пространстве CSS).
- Готовый файл для сайта: `public/hero3d/hero3d.js`, стили: `public/hero3d/hero3d.css`.

Пересборка после правок исходника:

```bash
cd tools/hero3d
npm install
npm run build
```

После пересборки поднять номер версии `?v=` у `hero3d.js` и `hero3d.css` на страницах услуг.
