# 3D-сцены первого экрана страниц услуг

- `hero3d.src.mjs` - исходник (Three.js + вёрстка в 3D-пространстве CSS).
- Готовый файл для сайта: `public/hero3d/hero3d.js`, стили: `public/hero3d/hero3d.css`.

Пересборка после правок исходника:

```bash
cd tools/hero3d
npm install
npm run build
```

После любой правки `hero3d.js` или `hero3d.css` обязательно поднять номер версии `?v=` на страницах услуг:
эти два файла выкладываются сжатыми и кешируются в браузере на год (см. `scripts/deploy-yandex.sh`).

Картинки на объёмных плашках: `public/hero3d/logo-*.webp` (квадрат, лучше 512×512).
